**A journey through data, algorithms, and meaningful discoveries.**

</div>

This repository documents my learning journey throughout the Big Data course, bringing together practical assignments, hands-on experiments, data analysis workflows, and projects developed throughout the semester.

The main objective is to transform theoretical concepts into practical experience by exploring datasets, processing information, discovering patterns, and extracting meaningful insights.
